# AI Builder

AI Builder is a new workspace for designing, prototyping, and shipping AI-powered applications.

## Status

The repository is being initialized. The first milestone is to define one focused use case, its users, and a measurable success criterion before selecting the implementation stack.

## First milestone

- Define the initial user and problem.
- Choose a small end-to-end prototype.
- Establish evaluation criteria and a repeatable test set.
- Add the application, model, and deployment architecture.
- Ship a usable first version and collect feedback.

## Repository structure

```text
docs/       Product and technical decisions
src/        Application source code
tests/      Automated tests and evaluations
```

## Getting started

1. Record the first product brief in `docs/product-brief.md`.
2. Select the implementation stack.
3. Add setup and run commands here with the first executable prototype.

## Security

Never commit API keys or other secrets. Store local configuration in `.env`; it is ignored by Git.
