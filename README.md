## Agent instruction files, explained

Two filenames often appear together, but your audience only needs the one supported by their tool:

```text
AGENTS.md   → Codex and tools that support the AGENTS.md convention
CLAUDE.md   → Claude Code
```

- **For this repository:** active instructions belong at `/AGENTS.md` and `/CLAUDE.md`.
- **For downloadable resource packs:** publish them under `resources/agent-instructions/<pack-name>/`.
- **For your audience:** include both files in a pack, plus a `README.md`; users copy the file that matches their tool.

Read the complete [placement and content guide](resources/agent-instructions/).

## How resources are published

Every resource gets a stable, descriptive folder so links from videos and social posts continue to work:

```text
resources/<category>/<resource-name>/
├── README.md          # Purpose, audience, setup, and limitations
├── downloadable-file # The resource itself
└── examples/          # Optional examples or demonstrations
```

Each resource is designed to be:

- **Understandable** — context before content
- **Practical** — built for real use, not just inspiration
- **Adaptable** — clear places to customise
- **Responsible** — security, privacy, and limitations are visible
- **Easy to share** — stable URLs and simple navigation
