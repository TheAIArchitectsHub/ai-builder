# Professional Coding Agent Contract

A concise repository operating contract for coding agents. It prioritises evidence, narrow changes, deterministic verification, secure execution, and clear handoffs.

## Choose your file

| Tool | File |
| --- | --- |
| Codex and tools supporting the AGENTS.md convention | [Download `AGENTS.md`](AGENTS.md) |
| Claude Code | [Download `CLAUDE.md`](CLAUDE.md) |

The two files contain the same operating principles in the same order, with tool-specific naming where appropriate.

## Install

1. Download the file for your coding agent.
2. Place it in the root of your repository.
3. Add project-specific commands, architecture, and conventions where needed.
4. Commit the file so every contributor and agent uses the same contract.

```text
your-project/
├── AGENTS.md   # Use with Codex-compatible agents
└── CLAUDE.md   # Use with Claude Code
```

You may include both files when a repository is used with both tool families.

## What it covers

It covers - Exact instructions for your coding agents that includes these in details in markdown files shared above:
1. Inspect before modifying
2. Minimise the change surface
3. Define done with evidence
4. Learn from failure
5. Stop and escalate when blocked
6. Verify before declaring completion
7. Preserve security boundaries
8. Keep instructions local
9. Communicate precisely
10. Use a consistent completion format
