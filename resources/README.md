## Publishing convention

Give every new resource its own descriptive, lowercase folder:

```text
resources/<category>/<resource-name>/
  README.md
  <downloadable files>
```

The resource `README.md` should explain:

1. What the resource does.
2. Who it is for.
3. What is included.
4. How to use and customise it.
5. Important limitations or security considerations.

Use permanent repository links in social posts so people can return to the latest version.
